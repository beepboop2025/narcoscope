How NarcoScope keeps the record honest

  • Source class stays visible. Official, illustrative, unavailable, stale and capability-only inputs never collapse into one status.
  • Units travel with numbers. Country, year, substance, reporting period and measurement type are kept beside each value.
  • Missing joins stay missing. NarcoScope does not fill absent links between lawful trade, enforcement, harm and finance with a causal story.
  • Safety is structural. The public product excludes point-of-sale, real-time, sub-street, navigable, synthesis-route, chemistry and yield information.
Interpretation rule: use each record for the event it actually observes. A price report is not a transaction ledger; a seizure is not total supply; a provisional death count is not final; a designation or reported origin is not an adjudication of guilt.
